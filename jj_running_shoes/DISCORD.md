**Running Shoes**

Kanto is a lot of walking. Hold **B** and the player runs — a tile in half the frames, legs cycling twice as fast to match, so it reads as running and not as fast-forward.

:athletic_shoe: Hold B to run at double speed on foot
:bike: The bicycle is untouched by default — or set **BIKE SPEED** to **MATCH RUN** and it keeps its 2:1 lead over a runner
:four_leaf_clover: Encounters, poison, daycare EXP and Repel all count tiles, so nothing about the game gets faster or rarer
:gear: Options for **2X** / **1.5X** / **OFF**, and an **ALWAYS** mode if you'd rather not hold a button

No setup: install and go.
