# Roadmap

Mod ideas, roughly in the order we plan to build them. Each becomes a
`jj_*` folder with its own manifest, readme, and headless tests when work
starts.

## Done

- **jj_repel_prompt** — asks "Use another?" when a Repel wears off.
- **jj_alternate_start** — begin a new game tutorial-free at any town,
  city, or flyable location.

## Next

- **More QoL mods** — to be grilled out before building.

## Later

- **jj_auto_field_moves** — automatic field move use. Walking into water
  starts surfing without opening the party menu, walking into a cuttable
  tree cuts it, and so on. Not every field move: FLY and anything
  destination-based still needs the menu.
- **jj_hm_field_unlock** — HMs work in the field without being taught.
  If a party pokémon *can learn* the move, having the HM in the bag or
  PC box plus the required badge is enough to use it in the field.
  Battle is unchanged: the move still has to be taught to be used in a
  fight. Pairs naturally with jj_auto_field_moves.
