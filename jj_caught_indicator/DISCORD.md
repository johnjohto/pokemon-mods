**Caught Indicator**

Ever weaken a wild pokémon, then check the dex to see if you even need it? No more. If you already caught one, a little pokeball icon shows up right next to its name in battle, just like the later generations.

:white_check_mark: Icon next to the name = already in your Pokédex
:x: No icon = new catch, time to get to work

Wild battles only, purely visual, nothing else changes. Install and forget it.
